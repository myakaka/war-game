# HANDOFF (2026-11-12) — 전투 효과 강화 (화면 연출만, 작업 전 태그 `stable-before-effects`) · 그 전: 확대/이동, PC 배치

## 끝난 것과 검증
- 직접 사격: 방향 전환(리치) → 주사위 → 병종별 발사(보병 3연발 섬광·가는 예광 3줄 / 대전차 섬광+뒤 연기·굵은 탄도 / 기갑 큰 섬광+포구 연기·굵은 예광 / 정찰·통신 작은 섬광). 명중 = 대상 위 불꽃(대전차·기갑은 폭발·파편) + 0.2초 흰·붉은 번쩍임과 2~3px 밀림 + 피해 숫자, 빗나감 = 대상 둘레 땅 먼지만. 격파 = 불꽃·연기 + 0.5초 페이드.
- 박격포: 발사 연기·섬광·고리, 포물선 포탄 + 땅 그림자, 한 칸 폭발. 포병: 큰 연기·섬광·먼지 고리, 높은 포물선, 중심 큰 폭발 뒤 주변 4칸이 0.1초 간격(위→오른쪽→아래→왼쪽). 아군 피해도 같은 연출.
- 흔들림(지도 `#board-frame` 의 CSS `translate` 만, 확대 transform 과 별개): 박격포 발사 1.5/낙하 2.5px, 포병 발사 4/낙하 6.5px(감쇠). 측정 최대 박격포 ≈2px, 포병 ≈6px, 상단 상태 줄 움직임 없음.
- 안개: 발사 효과는 발사 칸이 보일 때만, 비행은 발사 칸이 보이고 (대상이 보이거나 내 사격)일 때만. 시야 밖 발사의 착탄 시각은 고정값(거리 노출 없음), 밀림 방향 없음. 내 사격이 안개 속에 떨어지면 명중 여부와 같은 폭발. 쿨다운 연기는 내 포병만(`.cool-smoke`, 기존 쿨다운 배지 조건).
- 검증: `test.js` 114 통과(효과 4개: 명중/빗나감, 박격포·포병 확산·아군, 안개, 난수 분리), `check.js` 21항목 SAME, `layout-check` 32항목(대칭 전장 배치 화면 5항목은 지난 직접 배치 커밋의 의도한 변화라 기준값 갱신). 브라우저 1920 기본·리치, 390(CPU 4배 느리게: 평균 58fps, 최악 33ms), 확대 2배, 연출 줄이기 흔들림 0, 실제 5라운드 사격 8회 오류 없음.

## 확정된 결정
- 새 설정 없음: 기존 '연출 줄이기'(기본값 = 브라우저 `prefers-reduced-motion`)가 흔들림 끔·입자 절반·비행 생략, 기존 정지 표시(×, 칸 색칠)도 유지. 속도 설정은 효과 시간에도 곱함.
- 주사위 → 발사 순서(결과를 보고 연출). 공격 1회 연출 상한 1.5초(`FX.maxAttackMs`), 연기·먼지 여운은 기다리지 않아 다음 사격과 겹침.
- 아군 오폭 피해 숫자는 기존대로 주황(연출 자체는 구분 없음).
