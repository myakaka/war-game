# 규칙서 (rulesVersion 9)

현재 코드 기준. 수치의 원본은 `js/rules.js`, `js/ai-config.js`, `js/scenarios/*.js`. 규칙을 바꾸면 이 문서도 같이 고친다.

## 지도
- 시나리오마다 정사각 격자(현재 둘 다 16×16). 좌표는 (행, 열), 0부터. 행 0이 북쪽.
- **춘천 (1950):** 6~7행 소양강, 다리 (6,6)·(7,6)·(6,12)·(7,12). 25라운드, 국군(방어) 선공. 본부 북한군 (0,7)·국군 (15,8). 거점 서쪽 시가지 (9,6)·봉의산 (10,6)·동쪽 도하 출구 (9,12).
- **호스토멜 (2022):** 12라운드, 방어군 선공, 본부 없음. 거점 활주로 북단 (3,5)·중앙 (7,5)·남단 (12,5). 활주로(5열 2~13행)는 표식일 뿐 규칙상 평지. `w`는 이름만 "습지"이고 규칙은 논과 같음.

## 이동
- 아군 칸은 지나갈 수 있지만 멈출 수 없다. 보이는 적 칸은 지나갈 수 없다.
- 경로에 보이지 않던 적이 있으면 조우(매복): 그 앞 마지막 빈 칸에서 멈춘다. 다시 이동할 수는 없고, 남은 이동력이 공격 비용 이상이면 공격은 할 수 있다.
- 상대 소유 거점에서 이동을 마치면 점령한다. 상대가 다시 들어올 때까지 유지된다.

## 전투
- **공격 대상:** 직접 공격은 인접(상하좌우)한, 보이는 적만. 포병·박격포는 사거리 안의 아무 칸(빈 칸, 시야 밖 포함). `fires.blindFire: false`인 시나리오는 진영 시야 안 칸만.
- **이동 후 공격:** 남은 이동력 ≥ 공격 비용이면 가능, 명중률 −10. 포병·통신 제외(박격포는 가능). 공격하면 그 유닛의 행동이 끝난다.
- **명중률:** 50 + (공격력 − 방어력)×10 + 지형 + 통신 20 − 시야 밖 50 − 이동 후 10 − 간접 사격 추가 감점(`fires.<병종>.indirectPenalty`, 기본 0). 표적이 기갑이면 대장갑, 아니면 대인 공격력을 쓴다. 시야 밖 판정은 쏘는 유닛이 아니라 진영 시야 기준(아군 누군가 보고 있으면 감점 없음).
- **주사위:** 명중률을 10% 단위로 반올림(x5 올림)하고 10~90%로 제한한 뒤, d10이 (명중률 ÷ 10) 이하이면 명중.
- **통신 보너스:** 공격자 맨해튼 거리 2 안에 아군 통신 유닛이 있으면 +20(중복 없음).
- **피해:** 공격력 − 방어력(0 이하면 1). 포격이 명중하면 인접 4칸에도 피해 1(아군 포함). 박격포는 목표 칸에만 고정 피해 1(`fixedDamage`). 피해는 동시에 적용하고 HP 0이면 파괴.
- **간접 화력 (v7, 시나리오 `fires`):** 있으면 포병·박격포의 최대 사거리는 `fires.<병종>.range`, 쏜 뒤 `cooldown`턴 동안(자기 진영 턴 기준) 사격 불가, 이동은 가능. 쿨다운은 유닛의 `lastFiredRound`로 판정. 호스토멜: 안개 속 사격 가능, 포병 사거리 5·쿨다운 1, 박격포 사거리 4·쿨다운 0·추가 감점 0, 공격군 박격포 2기(1라운드, (3,9)·(7,10)). 춘천은 `fires`가 없어 v6 그대로.
  - 설정 메뉴 '화력'에서 사거리·쿨다운·추가 감점을 바꿀 수 있다(시나리오별 저장, 그 진영의 다음 턴부터). `blindFire`는 시나리오 값만. 시뮬레이션은 설정을 쓰지 않는다.

## 시야와 안개
- 시야는 유닛 위치에서 맨해튼 거리(병종 시야) 안의 칸. 지형은 시야를 가리지 않는다. 진영의 시야는 모든 유닛 시야의 합집합.
- 시야 밖 적은 렌더링하지 않고 로그·툴팁·`aria-label`·요약에서도 뺀다. 시야 밖 칸의 명중률은 `?`, 시야 밖에서 온 공격은 "출처 불명".
- 상대의 증원 일정은 어디에도 표시하지 않는다(HUD에는 자기 진영 도착 예정만).
- AI는 자기 시야와 최근 목격 기억을 쓰고, 상대 포병은 공개된 기본 배치 위치로 추정한다. 게임이 끝나면 전장 전체를 공개한다.
- `fires` 시나리오의 AI 간접 화력은 보이는 적만 쏜다(안개 속 추측 사격·대포병 추정 사격 없음). 박격포가 이동 후 쏠 때는 이동 뒤에도 진영 시야에 남는 표적만.
- 쿨다운 표시는 화면을 보는 진영 자신의 유닛에만. 안개 속 칸을 고르면 적 유무와 관계없이 같은 내용(`미확인 칸`, 명중률 `?`)을 보여 준다.

## 턴과 승리 조건
- 한 라운드 = `turnOrder` 순서대로 진영별 한 턴. 한 턴에 각 유닛이 한 번씩 행동한다.
- **행동 제한 (v6):** 한 턴에 행동할 수 있는 유닛 수는 시나리오 `activations`(역할별)로 정한다. 춘천 국군 5 · 북한군 6, 호스토멜 방어군 4 · 공격군 4.
  - 유닛이 그 턴에 처음 이동하거나 공격하는 순간 1회. 이어지는 이동 후 공격은 추가로 쓰지 않는다. 선택·대기는 쓰지 않는다. 포병 사격, 통신·정찰도 같다.
  - 한도를 다 쓰면 아직 행동하지 않은 유닛은 이동·공격할 수 없다. 이미 행동을 시작한 유닛은 그 턴의 이동 → 공격을 마칠 수 있다. 턴은 자동으로 끝나지 않는다.
  - 한도는 진영의 턴이 시작될 때 정해지고(소모 0), 그 턴 동안 바뀌지 않는다. 유닛 수가 한도보다 적으면 전원 행동. 증원이 와도 한도는 같다.
  - 설정 메뉴에서 켜기/끄기와 진영별 한도(1 ~ 그 진영 최대 유닛 수, 또는 제한 없음)를 바꿀 수 있고, 그 진영의 다음 턴부터 적용된다(시나리오별 저장). 시뮬레이션은 설정을 읽지 않는다.
  - `RULES.ENABLE_ACTIVATION_LIMIT = false`이거나 `activations`가 없으면 제한 없음(v5와 같은 동작). 되돌리기 기능은 없다.
  - 화면에는 자기 진영의 남은 행동만 보인다(HUD `행동 n/N`). 상대의 소모 횟수는 어디에도 표시하지 않는다.
  - AI: 한도가 있으면 행동하지 않은 유닛 전체의 후보(이동, 이동 후 공격, 제자리 공격)를 매번 다시 점수화해 하나씩 실행한다. 비교 값은 '그 유닛의 대기 점수보다 얼마나 나은가'이고, 대기보다 나은 후보가 없으면 남은 한도를 쓰지 않는다. 산개전술의 도하 최우선 이동은 다른 후보보다 먼저.
- **직접 배치:** 시작 전 배치 구역 안에서. 춘천은 국군 8~11행·2인 대전 북한군 4~5행, 호스토멜은 방어군만 2~13행·2~9열.
- **예약 투입:** 정해진 라운드에 그 진영 턴이 시작될 때 등장하고 그 턴부터 행동한다. 후보 칸이 막히면 3칸 안 가장 가까운 빈 칸(난수 없음), 없으면 다음 라운드로 미룬다. 상대 거점·본부 칸에는 놓지 않는다.
- **판정 순서:** ① `enterHQ` 적 본부에서 이동을 마치면 즉시 승리 → ② `annihilation` 적 전멸(도착 예정 유닛이 남아 있으면 전멸 아님) → ③ `holdObjectives(n)` 라운드 종료 시 거점 n개 이상 → ④ `surviveRounds(n)` n라운드를 버팀 / `roundLimitScore`·`roundLimitPoints` 마지막 라운드 종료 시 판정. 점수제의 `scoreTarget`은 점수를 받은 직후 판정.
- **거점 점유 (v8):** 기본(`sticky`)은 거점 칸에서 이동을 마친 진영이 소유하고 떠나도 유지. `objectiveControl: 'presence'`이면 지금 거점 안(여러 칸이면 어느 칸이든)에 유닛이 있고 상대 유닛이 없는 진영이 점유, 양쪽 다 있거나 아무도 없으면 점유자 없음(이동·격파·증원 도착 때마다 갱신). `holdObjectives`는 확인 시점에 n개 이상이면 바로 승리(연속 유지 라운드 없음).
- **라운드 제한 판정 (v8, `roundLimitScore`):** 마지막 라운드가 끝나면 점유 거점 수가 많은 쪽 → 같으면 남은 총 체력(도착 대기 유닛은 최대 체력으로 셈)이 많은 쪽 → 같으면 무승부. 양쪽이 동시에 전멸해도 무승부.
- **점수제 (v10, `roundLimitPoints`):** 거점을 점유한 동안 `objectivePoints` 점수가 쌓이고, 마지막 라운드가 끝나면 총점이 많은 쪽 → 남은 총 체력 → 무승부. `scoreTiming` `ownTurnEnd`(기본)는 각 진영이 자기 턴을 끝낼 때 그때 점유한 거점만, `roundEnd`는 라운드 끝에 양쪽 동시. 점유는 objectiveControl 규칙 그대로(다툼 중인 거점은 아무도 못 받음). `scoreTarget`이 있으면 한쪽 총점이 닿는 즉시 승리.
- **선공 (v8):** `firstMover`가 있으면 라운드 순서 = [선공, 후공]. `secondMoverBonus`는 후공 진영의 1라운드 턴에만 행동 한도를 그만큼 늘린다(기본 0, 행동 제한이 있을 때만).
- **춘천:** 북한군 = 본부 진입·전멸·거점 3개 / 국군 = 본부 진입·전멸·25라운드 생존.
- **호스토멜:** 공격군 = 거점 2개·전멸 / 방어군 = 12라운드 생존·전멸.
- **대칭 전장 (가상):** 16×16, 180도 회전 대칭, 14라운드, 러시아군(위) 선공, 행동 한도 5/5, 간접 화력은 호스토멜과 같은 값. 거점 3개(왼쪽 측면 (8,2), 중앙 마을 (7,7)~(8,8) 4칸 묶음, 오른쪽 측면 (7,13)), 점유 방식 `presence`. 양쪽 = 전멸·14라운드 점수 판정(v10: 거점 점수 왼쪽 1·중앙 2·오른쪽 1, 자기 턴을 끝낼 때 점유한 거점의 점수, 14라운드가 끝났을 때 총점 → 체력 → 무승부. 거점 2개 즉시 승리 없음). 고정 배치(직접 배치 없음), 증원 4라운드 보병 2, 8라운드 기갑 1·보병 1. AI는 중립 모드(`aiProfile: 'symmetric'`): 역할과 무관하게 양쪽이 같은 목표(점유하지 않은 거점, 지금 서 있는 아군 거점)와 점수(거점 위 머묾 14, 5라운드부터 라운드마다 접근 가중치 +10%)를 쓴다.
  - **새 대칭 AI (v2, `js/ai-intel.js`, 규칙 변화 없음):** 본 적 기억(신뢰도·불확실 반경, 공개된 시작 배치 포함), 보이지 않는 곳에서 온 간접 사격 단서(상대 포병 1기가 방금 쐈으면 다음 상대 턴은 쉰다고 추정), 위험 지도(다음 상대 턴 기대 피해)로 위험한 칸은 지원 아군이 있거나 상대 포병이 쉴 때만 진입, 포병·박격포의 사거리 확보와 안개 속 사격, 거점 근처 적 집중 공격·마무리·반격(거점에서 3칸 이내, 거점마다 최소 1기 수비). 안개: 상대의 보이지 않는 위치·체력·쿨다운·증원 현황은 읽지 않는다. 진단 프로필 `v1:<난이도>`(기존 중립 AI), `turtle`(수비 봇)은 화면에 없다.

## 시나리오 구조 (`js/scenarios/*.js` → `SCENARIOS.push({...})`, `index.html`에 script 한 줄 추가)
| 필드 | 내용 |
|---|---|
| `id`, `nameKey`, `descKey`, `subKey`, `scaleMeters` | 식별자, 표시 문자열 키, 한 칸의 실제 거리 |
| `map`, `sides`, `playerSide`, `turnOrder`, `rounds` | 지도, 진영(`{id: {role: 'def'|'att', nameKey, color}}`), 플레이어 진영, 턴 순서, 최대 라운드 |
| `hq`, `objectives` | 진영별 본부 칸 또는 `null` / `[{id, nameKey, shortNameKey, pos 또는 cells, startOwner}]` (`cells`: 여러 칸 거점) |
| `firstMover`, `secondMoverBonus` | 선공 진영 id(`turnOrder` 대신), 후공 1라운드 행동 한도 추가 |
| `objectiveControl` | `'sticky'`(기본) 또는 `'presence'` |
| `symmetric`, `aiProfile` | `true`면 회전 대칭 검사, `'symmetric'`이면 AI 중립 모드 |
| `aiProfiles` | 시작 화면 난이도 목록(프로필 id 배열, 생략하면 전체). 화면 표시만 바꾸고 AI 판단에는 쓰지 않음 |
| `deployments` | round 0 = 시작 배치(AI 추정 위치 겸용), round 1 이상 = 예약 투입(`pos` 또는 `count`+`cells`) |
| `placementZones`, `zoneLabelKey` | 직접 배치 구역, 안내 문구 키 |
| `victory` | 진영별 승리 조건 목록 (`enterHQ`, `annihilation`, `holdObjectives`, `surviveRounds`, `roundLimitScore`, `roundLimitPoints`) |
| `objectivePoints`, `scoreTiming`, `scoreTarget` | 점수제 (v10): 거점 id별 점수, 점수 시점(`ownTurnEnd`·`roundEnd`), 즉시 승리 점수(`null` = 없음) |
| `river`, `aiConstants` | 강 줄기와 도하 AI 상수(없으면 도하 전술이 꺼짐) |
| `terrainNames`, `overlays`, `arrivalRadius` | 지형 이름 바꾸기, 장식 표식, 예약 투입 탐색 거리 |
| `activations` | 역할별 한 턴 행동 한도 `{ def, att }` (1 이상의 정수). 없거나 `null`이면 제한 없음. 병력보다 큰 값은 안내만 출력 |
| `fires` | 간접 화력 `{ blindFire, <간접 병종>: { range, cooldown, indirectPenalty } }` (0 이상 정수, range ≥ 병종 최소 사거리). 없으면 v6 규칙 |
| `art` | 그림 세트 (PC 리치 테마 전용 장식: 지형 키별 그림, `terrainOffset`, `unitSet`, `overlays` runway/patch). 규칙 로직은 읽지 않고, 없으면 그 시나리오는 기본 테마만 |

불러올 때 `validateScenario`가 모든 시나리오를 검사하고, 오류가 있으면 콘솔에 출력한다.
